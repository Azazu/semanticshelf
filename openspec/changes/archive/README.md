# Archived changes

One directory per completed change, moved here when its specs were synced
into `openspec/specs/`. Each keeps the artifacts it was built from:
`proposal.md` (what and why), `design.md` (how, with the alternatives that
lost), `tasks.md` (every step and how it was verified), `review.md` (the
independent review rounds and their findings) and `handoff.md` (the state
at each session end).

## A note on the commit hashes in these records

`review.md` binds every review round to the commit it reviewed
(`Reviewed-Commit`), and the handoffs name commits too. Those hashes belong
to the history as it was on 2026-09-20. On that date the repository's
history was rewritten once, to remove third-party names that must not
appear in a public repository, so every hash recorded before the rewrite
no longer resolves.

The records themselves are unaltered: a review record is evidence and is
never edited after the fact, not even to repair a reference. Read the
hashes as the identity the commit had when it was reviewed, not as
something to look up.
